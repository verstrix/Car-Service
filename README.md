# Car System

Flask приложение за управление на автосервиз с роли за `manager`, `mechanic` и `client`.

## Какво включва
- управление на автомобили и клиентски данни
- склад и наличности за части
- работни поръчки със статуси, бележки и вложени части
- PDF експорт на сервизна поръчка
- справки за поръчки, приходи и ниска наличност

## Стартиране
1. Инсталирай Python 3.11+.
2. Отвори терминал в папката на проекта.
3. Инсталирай зависимостите:

```bash
pip install -r requirements.txt
```

4. Стартирай приложението:

```bash
python app.py
```

5. Отвори `http://127.0.0.1:5000`.

## Демо акаунти
- `manager / manager123`
- `mechanic / mechanic123`
- `client / client123`

## Проверка
Може да пуснеш бърза проверка с:

```bash
python -m unittest discover -s tests -v
```

## Забележка
SQLite базата се създава автоматично в `instance/car_service.sqlite3`.
