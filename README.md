# Car Service

Flask приложение за управление на автосервиз с роли за мениджър, механик и клиент.

## Функционалности

- вход в системата и различни права според ролята
- управление на автомобили, клиенти и потребители
- склад за части с количества, минимални наличности и цени
- работни поръчки със статуси, бележки, труд и вложени части
- автоматично намаляване на наличностите при добавяне на част към поръчка
- PDF експорт на сервизна поръчка чрез `reportlab`
- справки за приходи, статуси на поръчки, складова стойност и ниски наличности

## Изисквания

- Python 3.11 или по-нова версия
- `pip`

Зависимостите са описани в `requirements.txt`.

## Инсталация

1. Отвори терминал в папката на проекта.
2. Създай и активирай виртуална среда:

```bash
python -m venv .venv
source .venv/bin/activate
```

За Windows:

```bat
python -m venv .venv
.venv\Scripts\activate
```

3. Инсталирай зависимостите:

```bash
pip install -r requirements.txt
```

## Стартиране

```bash
python app.py
```

След стартиране отвори:

```text
http://127.0.0.1:5000
```

При първото стартиране приложението автоматично създава SQLite базата и демо данните.

## Демо акаунти

| Роля | Потребител | Парола |
| --- | --- | --- |
| Мениджър | `manager` | `manager123` |
| Механик | `mechanic` | `mechanic123` |
| Клиент | `client` | `client123` |

## Роли

- `manager` управлява потребители, автомобили, части, работни поръчки и справки.
- `mechanic` вижда и обработва назначените му работни поръчки.
- `client` вижда своите автомобили и може да създава заявки за сервиз.

## Тестове

```bash
python -m unittest discover -s tests -v
```

## Данни и файлове

- Основната база данни се създава в `instance/car_service.sqlite3`.
- Качените снимки се пазят в `app/static/uploads/`.
- Максималният размер на качван файл е 5 MB.
- Демо данните се добавят само ако в базата все още няма потребители.

## Полезни бележки

- Ако искаш чист старт, спри приложението и изтрий `instance/car_service.sqlite3`.
- PDF бутоните се скриват или връщат съобщение, ако `reportlab` не е наличен.
